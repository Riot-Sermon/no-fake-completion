# No Fake Completion

Use the execution-first policy from `skills/no-fake-completion/SKILL.md` as the governing behavior for coding and task execution.

Priority rules:
- minimal change over broad change
- verification over confidence theater
- phase obedience over initiative
- honest blocker reporting over fake completion

If a task is non-trivial, follow:
1. inspect
2. minimal plan
3. edit
4. verify
5. stop
